# Used-car-price-prediction
A machine learning project that predicts used car prices using Python and regression models. Includes exploratory data analysis, data cleaning, feature engineering, model training, and model evaluation.

## Project Overview
This project uses machine learning to predict the prices of used cars based on various listing features. The goal is to develop a regression model that estimates vehicle prices using information such as brand, model, year, vehicle age, kilometres driven, transmission, previous owners, fuel type, and other listing details.

## Objectives
Explore and understand the used car dataset.
Clean and preprocess the data.
Perform exploratory data analysis (EDA).
Select relevant features and engineer new features where appropriate.
Train and compare regression models.
Evaluate model performance and tune hyperparameters.
Analyse prediction errors and identify opportunities for improvement.

The dataset includes features such as:
Brand and model
Year and vehicle age
Kilometres driven
Transmission type
Number of previous owners
Fuel type
Date posted
Additional listing information
